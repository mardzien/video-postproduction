## 🎨 Eksperymentuj z Instrumentami!

Każdą templatekę możesz przetestować z dowolnym instrumentem:

```bash
# Przykład: Mario w różnych wersjach
postprod shorts --template mario --instrument 0 --input video.mp4   # Piano
postprod shorts --template mario --instrument 19 --input video.mp4  # Organ
postprod shorts --template mario --instrument 30 --input video.mp4  # Guitar
postprod shorts --template mario --instrument 48 --input video.mp4  # Strings
postprod shorts --template mario --instrument 52 --input video.mp4  # Choir
postprod shorts --template mario --instrument 81 --input video.mp4  # EDM
```

## 🚀 Quick Start

```bash
# 1. Zobacz co masz dostępne
postprod shorts --list-templates

# 2. Użyj templateki
postprod shorts --template gravity_falls --input recordings/video_*.mp4

# 3. Wypróbuj inny instrument
postprod shorts --template gravity_falls --instrument 40 --input video.mp4

# 4. Przetwórz wsadowo
postprod shorts --template mario --input recordings/*.webm --auto-number
```
